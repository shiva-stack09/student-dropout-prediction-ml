# Student Dropout and Academic Success Prediction Using Machine Learning

## 📌 Project Overview

This project uses machine learning to predict student academic outcomes based on demographic, enrollment, financial, academic, and socioeconomic information.

The model classifies students into three possible outcomes:

- **Dropout**
- **Enrolled**
- **Graduate**

The project follows a complete machine learning workflow, including data exploration, preprocessing, model development, evaluation, feature importance analysis, and sample prediction.

---

## 🎯 Objectives

The main objectives of this project are:

- Analyze student demographic and academic information.
- Explore patterns associated with different student outcomes.
- Preprocess numerical and categorical variables.
- Build multiclass classification models.
- Compare Logistic Regression and Random Forest.
- Evaluate model performance using multiple classification metrics.
- Analyze Random Forest feature importance.
- Demonstrate prediction on a sample student record.

---

## 📊 Dataset

The dataset contains:

- **4,424 student records**
- **35 columns**
- **34 input features**
- **1 target variable**

### Target Variable

The `Target` column contains three classes:

| Outcome | Description |
|---|---|
| Dropout | Student classified as having dropped out |
| Enrolled | Student currently classified as enrolled |
| Graduate | Student classified as having graduated |

### Target Distribution

| Outcome | Number of Students |
|---|---:|
| Graduate | 2,209 |
| Dropout | 1,421 |
| Enrolled | 794 |

The dataset contains no missing values and no exact duplicate records.

## 🛠️ Data Preprocessing

The following preprocessing workflow was used:

1. Separated the target variable from the input features.
2. Identified categorical and numerical variables.
3. Used **One-Hot Encoding** for categorical features.
4. Passed numerical features through the preprocessing pipeline.
5. Used an **80/20 train-test split**.
6. Applied **stratified sampling** to preserve the target-class distribution.
7. Used a Scikit-learn `Pipeline` and `ColumnTransformer` to keep preprocessing consistent between training and prediction.

---

## 🤖 Machine Learning Models

Two multiclass classification models were developed.

### 1. Logistic Regression

Logistic Regression was used as a baseline classification model.

It provides a relatively simple model against which the more complex ensemble model can be compared.

### 2. Random Forest

Random Forest is an ensemble learning algorithm based on multiple decision trees.

It was selected because it can model nonlinear relationships and interactions between features and supports multiclass classification.

## 🌲 Feature Importance

Random Forest feature importance was analyzed to identify the features that contributed most strongly to the model's predictions.

The analysis includes the top 15 features and a visualization of their relative importance.

Feature importance indicates how much the trained model relied on a feature during prediction. It should **not** be interpreted as proof that a feature directly causes a particular student outcome.
